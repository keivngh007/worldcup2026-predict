# 2026世界杯智能预测App - 产品需求文档

## 1. 产品概述
一款专为移动端设计的2026美加墨世界杯智能预测应用，基于球队实力数据、场地数据、天气数据及历史对战记录，通过智能算法为每场比赛提供胜负预测和进球数预测，并以可视化图表呈现分析结果。
- 目标用户：足球爱好者、体育竞猜用户、世界杯观赛人群
- 核心价值：用数据驱动的智能预测替代主观判断，为用户提供权威、直观的世界杯赛事分析

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 浏览所有预测数据、赛程、球队信息 |
| 收藏用户 | 本地存储 | 收藏比赛、自定义关注球队、接收提醒 |

### 2.2 功能模块
1. **首页**：赛事概览、今日焦点比赛预测、倒计时
2. **赛程页**：完整104场比赛赛程、分组赛/淘汰赛切换、比赛预测入口
3. **预测详情页**：单场比赛深度预测分析、胜负概率、进球数预测、关键因素
4. **球队页**：48支队伍详细数据、FIFA排名、近期战绩、阵容分析
5. **数据看板页**：赛事统计总览、热门预测排行、历史预测准确率

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深墨绿(#0A1628) + 金色(#D4AF37) — 呼应世界杯奖杯的尊贵感
- 辅助色：翡翠绿(#1DB954)用于胜方高亮，珊瑚红(#FF6B6B)用于负方警示
- 按钮风格：圆角胶囊按钮，带微光渐变
- 字体：标题使用粗体无衬线体，数据使用等宽字体
- 布局：底部Tab导航，卡片式内容，移动端优先
- 图标风格：线性图标，2px描边，金色点缀

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 倒计时 | 大号数字翻牌动画，金色渐变背景 |
| 首页 | 焦点比赛 | 横滑卡片，球队国旗+预测概率条 |
| 赛程页 | 阶段Tab | 顶部横向滚动Tab，当前阶段高亮 |
| 赛程页 | 比赛卡片 | 左右对称布局，中间VS，底部概率条 |
| 预测详情页 | 胜负概率 | 环形进度图，三段颜色区分 |
| 预测详情页 | 进球预测 | 双色柱状图+概率分布曲线 |
| 预测详情页 | 关键因素 | 图标标签云，带影响权重条 |
| 球队页 | 分组展示 | 网格卡片，每组一行，国旗+队名+排名 |
| 数据看板 | 冠军预测 | 横向条形图，渐变色条 |
| 数据看板 | 射手榜 | 排行榜列表，头像+姓名+预期进球 |

### 4.3 响应式设计
- 移动端优先设计，适配375px-428px宽度
- 触摸优化：最小点击区域44px，卡片滑动操作
- 竖屏为主，所有图表适配竖屏展示
- 底部安全区域适配（iPhone刘海屏等）

### 4.4 数据来源说明
- 球队数据：内置48支队伍的FIFA排名、近期战绩、攻防数据
- 场地数据：16座场馆的海拔、气候、草皮类型等特征
- 天气数据：各举办城市6-7月历史天气模式（温度、湿度、降水概率）
- 预测算法：基于Elo评分+泊松回归+蒙特卡洛模拟的综合预测模型
